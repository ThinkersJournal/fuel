# fuel-loaders

Model-loading support for the fuel ML framework — HF config.json resolution rules, load-progress reporting, and GGUF/imatrix/tokenizer glue over fuel-formats' wire parsers. Knows nothing about Tensor, Storage, or Device.

Part of the [Fuel](https://github.com/ciresnave/fuel) workspace: a DAG-first, lazy-only ML framework for Rust. Licensed under MIT OR Apache-2.0.
