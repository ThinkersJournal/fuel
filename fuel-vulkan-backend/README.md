# fuel-vulkan-backend

Vulkan GPU executor for the fuel lazy-graph layer. Uses Vulkane for device management and precompiled SPIR-V from fuel-vulkan-kernels (sources in fuel-kernels-source).

Part of the [Fuel](https://github.com/ciresnave/fuel) workspace: a DAG-first, lazy-only ML framework for Rust. Licensed under MIT OR Apache-2.0.
