# fuel-lazy-examples

Runnable binaries demonstrating fuel's Phase 6a lazy graph layer. Kept separate from fuel-examples so it does not pull in the eager-path model code in fuel-transformers / fuel-nn.

Part of the [Fuel](https://github.com/ThinkersJournal/fuel) workspace: a DAG-first, lazy-only ML framework for Rust. Licensed under MIT OR Apache-2.0.
