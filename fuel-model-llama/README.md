# fuel-model-llama

The LLaMA-family lazy-graph decoder for the fuel ML framework — the canonical base every downstream LLaMA-family model (LLaMA-2/3, LLaVA, Mistral, DeepSeek-2) builds on.

Part of the [Fuel](https://github.com/ThinkersJournal/fuel) workspace: a DAG-first, lazy-only ML framework for Rust. Licensed under MIT OR Apache-2.0.
