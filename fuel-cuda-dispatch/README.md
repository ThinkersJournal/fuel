# fuel-cuda-dispatch

CUDA (baracuda) kernel bindings for fuel-dispatch: the CUDA dispatch wrappers, the FKC link registry and the one-call registrar (above fuel-dispatch, like fuel-vulkan-dispatch)

Part of the [Fuel](https://github.com/ciresnave/fuel) workspace: a DAG-first, lazy-only ML framework for Rust. Licensed under MIT OR Apache-2.0.
