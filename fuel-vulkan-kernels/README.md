# fuel-vulkan-kernels

Precompiled SPIR-V kernels for the Fuel Vulkan backend. Sources live in fuel-kernels-source; SPIR-V here is committed and consumed via include_bytes! so downstream consumers need no shader toolchain at build time.

Part of the [Fuel](https://github.com/ThinkersJournal/fuel) workspace: a DAG-first, lazy-only ML framework for Rust. Licensed under MIT OR Apache-2.0.
